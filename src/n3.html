Attention räknat för hand

Ett head, tre tokens och två dimensioner i stället för 128. Vi räknar vad ”den” hämtar från ”Katten”, ”satt” och sig själv. Varje tal nedan är uträknat, inget är påhittat.

Hela forward pass som kod

Allt i modulen på en skärm, som PyTorch-lik pseudokod för en sekvens. Jämför rad för rad med tensorspårningen.

Samma funktion gör både prefill och decode. Enda skillnaden är T: vid prefill är T promptens längd och cachen tom, vid decode är T = 1 och cachen innehåller allt tidigare.

repeat_kv visar GQA som idé: varje KV head används av 4 query heads. Riktiga kernels kopierar inget, de indexerar bara.

Koden i vLLM (models/llama.py) har samma struktur: qkv_proj, o_proj, gate_up_proj, down_proj. Attention och cache-hanteringen ligger i en separat backend.

def forward(ids, pos, cache):                     # ids [T]
    x = E[ids]                                    # [T, 4096]
    for l in range(32):
        h = rmsnorm(x, g1[l])                     # [T, 4096]
        q, k, v = split(h @ W_qkv[l])             # [T,4096] [T,1024] [T,1024]
        q = q.view(T, 32, 128).transpose(0, 1)    # [32, T, 128]
        k = k.view(T,  8, 128).transpose(0, 1)    # [ 8, T, 128]
        v = v.view(T,  8, 128).transpose(0, 1)    # [ 8, T, 128]
        q, k = rope(q, pos), rope(k, pos)

        K, V = cache[l].append(k, v)              # [8, ctx, 128]   ctx = gamla + T
        K, V = repeat_kv(K, 4), repeat_kv(V, 4)   # [32, ctx, 128]

        S = q @ K.transpose(-1, -2) / sqrt(128)   # [32, T, ctx]
        S = S + causal_mask                       # −inf där key ligger efter query
        P = softmax(S, dim=-1)                    # [32, T, ctx]
        o = (P @ V).transpose(0, 1).reshape(T, 4096)
        x = x + o @ W_o[l]                        # [T, 4096]

        h = rmsnorm(x, g2[l])
        gate, up = split(h @ W_gate_up[l])        # [T, 14336] × 2
        x = x + (silu(gate) * up) @ W_down[l]     # [T, 4096]

    h = rmsnorm(x[-1], g_final)                   # [4096]   bara sista positionen
    return h @ W_U                                # [128256] logits
