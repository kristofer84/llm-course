# Localized teaching examples

## Agreed scope

Use natural localized sentences and adapt demonstration lengths, indices, counts and layouts—not
one-for-one relabeling of Swedish chips. Swedish remains Swedish, English uses “The cat sat on the
mat”, and German uses “Die Katze saß auf der Matte”. German causal continuation uses “denn sie war
müde”, preserving grammatical word order. Course titles remain localized (unchanged).

## Data and truth boundaries

`src/examples/{sv,en,de}.json` are reproducible scenario packs generated by
`tools/build_examples.py`. No model inference is used. Distinguish:

1. **Verified Llama 3 byte-level tokenization snapshots:** prompt, full sentence, numeric example,
   embedding input IDs, cache/training/packed/speculative token sequences. One BOS is explicitly
   prepended where indicated; no chat template is applied. IDs and pieces must reconstruct exactly.
2. **Illustrative character-pair merges:** a local word and its own valid merge sequence. These do
   not claim to reproduce the real byte-level tokenizer; character counts and UTF-8 byte counts can
   differ (German umlauts).
3. **Word-level toy Attention/MLP scenes:** articles and German punctuation receive their own
   positions. Semantic roles (subject, pronoun, preposition, etc.) are explicit indices. The weights
   are handcrafted, not measured Llama Attention. These are not real BPE boundaries.
4. **Three-row worked Attention:** selected local role labels and identical handcrafted K/V/Q. It
   is a mathematical toy vocabulary, not a complete naturally tokenized sentence. Arithmetic is
   calculated; the inputs are not measured model parameters.
5. **Random miniature transformer / grammar-state next-word graph / detector and lens examples:**
   each has its own localized vocabulary. Mechanics or arithmetic can be real while the examples,
   distributions and weights remain illustrative. No quality inference follows from them.

Architectural constants (4096, 32 layers, 128256 vocabulary, KV bytes/token) do not change. An
independent tensor exercise may keep a declared T=7, but must not imply it describes the localized
prompt. Prompt-linked T, indices, targets, work totals and layouts must come from the pack.

## Tokenizer provenance

Snapshot artifact: Meta-Llama-3-8B tokenizer.json, 9,085,698 bytes.

- Official revision: `8cde5ca8380496c9a6cc7ef3a8b46a0372a1d920`.
- Official Hugging Face tree API reports Git blob `b197f72effb9d5ed16ee0f5663e11e4cfac2ba62`.
- Public mirror: `NousResearch/Meta-Llama-3-8B`, revision
  `315b20096dc791d381d514deb5f8bd9c8d6d3061`.
- Downloaded mirror bytes match that official Git blob exactly; SHA-256
  `e134af98b985517b4f068e3755ae90d4e9cd2d45d328325dc503f1c6b2d06cc7`.
- Reproduced with `tokenizers==0.22.2`; vocabulary 128256, BOS ID 128000.

The tokenizer file is a developer-time verification input, not bundled into the HTML or downloaded
at runtime/normal build. Reproduce with `python tools/build_examples.py --tokenizer <file>`; add
`--write` only when intentionally updating snapshots. Normal CI validates committed data and its
relationships without an external model/tokenizer dependency.

Current verified prompt T including BOS: SV 6, EN 6, DE 8. In particular, Swedish ` satt` splits
into ` s` + `att`; the former five-position schematic was not real Llama tokenization.

## Runtime/build contract

The main integrator owns scenario packs/generator, build, i18n engine, docs and shared tests.
Contributing agents own only their assigned JS/catalog files.

- `EX` is the selected immutable scenario pack, available inside the shared course closure before
  interactives run. The same pack is inspectable as `window.COURSE_EXAMPLE` for browser tests.
- `EX.words`, `EX.scene`, `EX.tokenizer`, `EX.bpe`, `EX.sampling`, `EX.training`, `EX.cache`,
  `EX.speculative`, `EX.workedAttention`, `EX.mini`, `EX.detectors`, `EX.lens`, `EX.lm` and
  `EX.weightInputs` are demonstration-specific datasets. Read actual JSON to use exact field names.
- `EX.scene.contextRoles` excludes BOS; `attentionRoles` includes BOS. Never reuse one for the other.
- All `EX.vars` are default interpolation variables for **both** `L.t()` and static Swedish fill.
  Use e.g. `{{example_prompt_T}}`, `{{example_prompt_ids}}`, `{{example_pronoun}}`,
  `{{example_lens_prompt}}`, `{{example_primary_chips}}`. Explicit call-site variables still win.
  Keep each template's placeholders and markup identical across SV/EN/DE.
- Call `exampleSvg(svg, width, height, minWidth)` for length-sensitive diagrams. It configures a
  viewBox and an accessible horizontally scrollable wrapper; do not shrink long token arrays into
  illegible miniatures. Existing expansion/keyboard controls must continue to work.
- Raw example labels are plain data: do not pass them through `L.t()` as lookup keys. UI prose stays
  in catalogs. Remove legacy Swedish identity catalogs after all consumers are migrated.

## Acceptance

- No old Swedish example text in rendered English/German, including dynamic SVGs, input/target
  sequences, caches, mini-model outputs, detector/lens lists, and all graph branches.
- Token/character/byte counts, exact leading spaces, IDs, prefix/suffix reconstruction, shifted
  training targets, speculative accepted/replacement indices, packed slots and matrix shapes agree.
- All causal rows normalize, reference only valid earlier positions, and pronoun selection points
  to the appropriate local subject rather than an article or unrelated token.
- Full/cached miniature-transformer logits agree per locale; no random-model quality claim.
- Existing SV/EN/DE navigation, hashes, stored answers, language selection, desktop/mobile layout,
  diagram keyboard activation/focus, code copying and expansion remain tested.
- Translation coverage/markup/numeric/placeholder/multiline contracts and provenance remain strict.
- Single offline artifact; full CI, deployed bytes verified; completed branches cleaned up.
